### What the manual pass actually covered

Real `cargo build --release` binary, real `yt-dlp`/`mpv`/`ffprobe` on `PATH`, driven inside a detached `tmux` session against a scratch `$HOME` (so it never touched real trovers data), keystrokes sent with `tmux send-keys`, screens checked with `tmux capture-pane`, on-disk `.toml` files read directly to confirm what actually got written:

- `A` → typed a name → an empty album appeared as an open header (`0 tracks`, `collapsed = false`), file on disk had `kind = "album"`, `parent = "Default"`, no `source_folder`.
- `F` on a single file, `Tab`-cycled to that album by name → the popup's new `Playlist: <name>  [tab] cycle` line (added during this pass — see below) showed the cycle working, and the file appeared as a row in the album's group immediately, with no switch-away-and-back.
- Cursor moved onto that row, `r` pressed → footer said "Shuffle on for Smoke Test Album"; the album's own `.toml` gained `shuffle = true` while `Default.toml` stayed `shuffle = false`.

**Found and fixed during this pass, not by any automated test**: the folder/file prompt had no visible target indicator at all — `UrlInput` shows "Playlist: `<name>`  [tab] cycle" but `FolderInput` showed nothing, so `Tab`-cycling `target_list_for_add` was invisible. Generalized `render_input_overlay`'s `show_playlist_hint` to cover `FolderInput` too, and added `ui::folder_input_target_display` (mirrors `url_input_target_display`, defaulting to `"Auto"`). No test caught this because every test drives `target_list_for_add` and the resulting behavior directly, never the popup's rendered text.

**Not covered by this pass** — genuinely needs a person: importing a *folder* (vs. the one file exercised above), the folder×explicit "second folder into an already-linked album" scenario (covered by an automated test instead, task 5.2/5.4), actually starting playback (`Enter`/`Space` spawning real `mpv`), video windows, and anything requiring a real audio/video file rather than a handful of random bytes with a media extension.
